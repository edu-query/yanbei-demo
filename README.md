# 研倍 · 材料贸易工作台（样板演示）

库存 / 销售 / 采购价格三本账合成一本的在线工作台样板。

## 怎么打开

直接在浏览器访问本仓库的 Pages 地址。登录页已预填演示账号，点「登 录」即可：

| 账号 | 密码 | 能看到什么 |
|---|---|---|
| `lily` | `123456` | 老板视角：全部数据，含销售价与毛利 |
| `xiaowang` | `123456` | 业务员视角：仅本人销售单，看不到毛利 |
| `caiwu` | `123456` | 财务视角：可看成本与毛利，不能改库存 |

## 建议先看这 4 个地方

1. **智能查价** —— 输入「铁粉」，一屏给出成本价、历史成交价、供应商最新报价、建议报价区间
2. **库存管理** —— 点「＋ 销售出库」，填数量后毛利实时算出来；出库超库存会被拦下
3. **采购价格** —— 左边选产品，右边一屏比完所有供应商，最低价自动标绿
4. **切换身份** —— 右上角退出，用 `xiaowang` 登录，销售价和毛利会消失

## 说明

- 页面内数据是**按材料贸易结构生成的演示数据**（铁粉 / 氧化铁红 / 钛白粉 / 硫酸钡等），不是真实业务数据
- 演示版数据存在**你自己浏览器本地**，换设备看不到，也不会上传到任何地方
- 正式版将接入云端数据库与登录，多人共用一份数据、手机电脑同步
